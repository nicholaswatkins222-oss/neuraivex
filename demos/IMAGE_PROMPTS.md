# Demo Image Prompts — Higgsfield / nano banana

Every demo homepage in this folder currently uses Unsplash photos as placeholders. When Higgsfield API access is configured, replace each image with one generated from the matching prompt below. Final images should be saved to `demos/images/{demo-slug}/{role}.jpg` and the Unsplash URL replaced with the local path.

**Image conventions:**
- Hero shots: 1600×900, story-driving, no on-image text
- Card thumbs (gallery): 900×560 derived from hero
- Section images: 1200×800 unless noted
- No model faces unless the style brief explicitly calls for portrait work (Lookbook, Light Room people work)
